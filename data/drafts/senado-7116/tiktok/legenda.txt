Você se interessa por economia? Este projeto altera as regras de gestão financeira do governo federal.

Este projeto muda as ferramentas que o governo federal usa para controlar a economia. O objetivo é buscar o equilíbrio das contas públicas e estimular o crescimento do país.

O que o projeto faz:
• Altera as regras atuais de gestão das contas públicas federais.
• Cria novos instrumentos para o governo buscar a estabilidade econômica.
• Define medidas para tentar melhorar o crescimento socioeconômico do Brasil.
